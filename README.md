# SafeDose AI 💊
### Intelligent Medication and Injection Safety System

**SafeDose AI** is a working mobile-first web prototype developed for the **USPF Changemaker Challenge**. It demonstrates how lightweight, AI-assisted workflows can reduce preventable medication errors and unsafe injection practices in resource-constrained Nigerian healthcare settings.

---

### 🚨 IMPORTANT SAFETY DISCLAIMER
**This is a demonstration prototype, NOT a clinically validated medical device.** 
- All patient and medication data is 100% fictional.
- It does not prescribe, diagnose, or calculate real patient doses.
- It does not authorise real injections.
- Clinical decisions must always remain with qualified healthcare professionals.

---

### 🎯 The Three Core Features
1. **Smart Medication Verification:** Simulates QR/barcode scanning to cross-reference patient IDs with medication records, instantly flagging identity mismatches or expiry risks.
2. **Injection Safety Intelligence:** A strict digital preparation checklist that ensures hand hygiene, sterile equipment, and sharps disposal protocols are met before a procedure.
3. **Early-Warning Monitoring:** A post-medication logging system that records simulated patient vitals and flags adverse reactions for simulated escalation to senior clinicians.

---

### 💻 Technical Architecture
- **Frontend:** Single-page application (SPA) built with lightweight HTML, CSS, and Vanilla JavaScript.
- **AI Integration:** Powered by **Groq (Llama 3.3)** for real-time, safety-constrained educational support.
- **Design:** Mobile-first, highly responsive, and optimized for low-bandwidth environments using no external libraries.
